# LMIDE
This is an IDE designed to program LMC code inside,
the instruction set is based on peter higgins instruction set,
taking his original commands, and expanding the set
the commands are as follows:

## Commandset

INT - integer
CHA - Character
FLO - Floating point number
DUB - Double Number

HLT - halt
ADD - add
SUB - subtract
STA - store at
LDA - Load from
BRA - Branch always
BRZ - Branch if zero
BRP - Branch if zero or positive
INP - input
OUT - outpu
OTC - Output as character/s
DAT - is there data at position
